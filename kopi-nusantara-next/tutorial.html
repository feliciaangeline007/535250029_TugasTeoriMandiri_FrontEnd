Verifikasi Node.js, npm, dan Instalasi Proyek Next.js

Sebelum membuat proyek Next.js, pastikan Node.js dan npm sudah terinstal pada komputer dengan menjalankan perintah verifikasi versi di terminal: 

node -v
npm -v

Selanjutnya, buat proyek Next.js baru bernama kopi-nusantara-next menggunakan create-next-app@latest dengan opsi konfigurasi berikut: 

npx create-next-app@latest kopi-nusantara-next

Struktur Folder Proyek Next.js (App Router)

Setelah instalasi selesai, struktur direktori utama pada folder kopi-nusantara-next/ adalah sebagai berikut: 

kopi-nusantara-next/
├── app/
│   ├── favicon.ico       # Ikon tab browser
│   ├── globals.css       # Styling global & tema Kopi Nusantara
│   ├── layout.tsx        # Root layout (metadata & Bootstrap 5.3.3 stylesheet)
│   └── page.tsx          # Halaman utama (/) dengan komponen Kopi Nusantara
├── public/               # Aset statis publik (SVG, gambar)
├── eslint.config.mjs     # Konfigurasi linter ESLint
├── next.config.ts        # Konfigurasi Next.js
├── package.json          # Daftar dependencies & script npm
└── tsconfig.json         # Konfigurasi TypeScript

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (

      <head>

      </head>
      <body>{children}</body>

  );
}

Menjalankan Development Server (npm run dev)

Untuk menjalankan aplikasi Next.js secara lokal di komputer Anda, buka terminal dan jalankan perintah berikut: 

cd kopi-nusantara-next
npm install
npm run dev
Tips Pemeriksaan Kualitas Kode: Anda juga dapat menjalankan npm run lint untuk memeriksa aturan ESLint dan npm run build untuk memverifikasi proses production build Next.js.
